# SQROCK Frontend Development — Phase 1

The guideline says to complete any 3 of 4 projects in the first 15-day phase. This package completes **Task 1 Personal Portfolio, Task 2 Movie Website, and Task 4 Job Portal**.

## Task 1 — Personal Portfolio
Home/hero, About, skills, 3 projects, resume download, contact details/form, social links, responsive design and smooth navigation.

## Task 2 — Movie Website
Hero/banner, popular movies, navigation/footer, movie poster cards with title/rating/year/description, search, all requested genres, responsive layout and hover effects.

## Task 4 — Job Portal
Hero/search, featured jobs, navigation, job cards, title/location/salary/type/date/apply, job details modal, login/register UI with candidate/employer roles, employer post-job UI, candidate application UI, companies/about sections and responsive corporate design.

## REQUIRED BEFORE SUBMISSION
1. Replace `Your Name`, email, phone, education and placeholder social links with your own details.
2. Test all 3 projects on desktop and mobile.
3. Push source code to GitHub.
4. Deploy each project using GitHub Pages, Netlify or Vercel.
5. Take screenshots of the required sections and functionality.
6. Create the LinkedIn post with screenshots/demo images, technologies used and learning experience.
7. Tag Sqrock IT Solutions.

## Run locally
Open each `index.html` in a browser or use VS Code Live Server.
